voxco-session-reconnect

About
This userscript is specifically designed for use with the Voxco CATI/Agent software platform.
Learn more about Voxco and its survey research software: https://www.voxco.com/

It helps mitigate session interruptions by attempting to reconnect and retry requests when the agent encounters a disconnection or receives an empty response during an active interview session.

This script has only been tested with Voxco environments and is not intended for use with other survey, contact center, or CATI platforms. Compatibility with future Voxco versions is not guaranteed.

Features
Attempts to reconnect and repeat request when encountering disconnect or empty response during session

*Note
Currently is still in a debugging phrase and is not at all reliable.

Installation
1. Go the "Extension" in your browser
2. Search and install "Tampermonkey"
3. Copy "voxco-session-reconnect.js" and add as new userscript in Tampermonkey
